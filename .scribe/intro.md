# Introduction

Dokumentasi resmi API Backend DNA Tour & Travel Umrah Management System.

<aside>
    <strong>Base URL</strong>: <code>http://localhost:8000</code>
</aside>

    Selamat datang di Dokumentasi API Backend DNA Tour & Travel.
    Dokumentasi ini menyediakan informasi lengkap mengenai seluruh endpoint API yang tersedia untuk pengelolaan Pendaftaran Jamaah, Paket Umrah, Kloter Keberangkatan, Rundown Activity, Pembagian Kamar (Room Meet), serta Transaksi Keuangan.

    <aside>Gunakan header `Authorization: Bearer {token}` pada setiap request yang membutuhkan autentikasi (diperoleh dari endpoint `/api/login`).</aside>
